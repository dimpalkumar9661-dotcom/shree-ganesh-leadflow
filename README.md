# Shree Ganesh LeadFlow

A customer inquiry and lead management prototype built with Python, SQLite, HTML, CSS and JavaScript.

## Features
- Capture customer inquiries through a website form
- Save leads in a SQLite database
- View and search leads in an admin dashboard
- Track lead statuses: New, Contacted and Converted
- Protect lead access with an admin token

## Verified locally
The dashboard loaded an existing lead successfully. A second test inquiry was submitted through the website and appeared in the dashboard.

## Project files
- app.py — Python server and database operations
- index.html — Website and inquiry form
- dashboard.html — Lead management dashboard

## Current stage
Working local prototype developed with AI assistance. Online hosting and automated follow-up drafts are planned next.

Customer data, database files and admin tokens are excluded from this repository.
